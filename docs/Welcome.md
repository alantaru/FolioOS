# Welcome to FolioOS

This is a sample document. Delete it (or keep it as a manual).

## The basics

- **Ctrl+S** saves, **Ctrl+Shift+S** saves under another name or exports.
- **Ctrl+O** opens the file manager: folders, drives, create, rename and delete.
- **Ctrl+P** shows the formatted text, like a book.
- **Ctrl+K** opens the palette with every command — including **Language**.
- To start this computer straight into FolioOS, **Ctrl+K › Install FolioOS on this computer**
  puts it on the disk, alone or next to the system that is already there (beta).

## Writing without distractions

- The bars fade away while you type and come back when you move the mouse.
- **F2** focus mode: sentence, paragraph or line highlighted.
- **F3** typewriter: the current line always stays in the center.
- **F4** timed writing sprint, with a bell at the end.
- **F11** zen mode.
- Type `--` for an em dash (—) and `...` for an ellipsis (…).

## Markdown

Use `#` for chapters, `##` for sections, `*italic*`, `**bold**`, `> quotes`,
lists with `-` and tasks with `- [ ]`.

> Write with your heart. Edit with your head.
